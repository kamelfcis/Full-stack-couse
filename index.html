03ASP.NET Core, SQL & REST APIsASP.NET Core · SQL Server · Entity Framework Core+
  • ASP.NET Core setup, HTTP pipeline, routing, controllers, middleware and dependency injection.

  • RESTful API design, DTOs, model binding, validation and error handling.
  • Swagger/OpenAPI documentation, services and data-access patterns.
PRACTICE: Create a database-driven REST API.

  • Authentication and authorization: ASP.NET Identity, JWT, roles, claims and policies.

  • Unit and integration testing with xUnit and Moq; API testing with Postman.
  • Logging, diagnostics, async performance and maintainable code structure.
PRACTICE: Secure and test your backend.

  • Responsive Angular pages styled with CSS, Bootstrap or Tailwind.
